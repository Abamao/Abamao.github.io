一句话版本

解压后直接双击 exe 就能用，默认不会自动更新。适合不熟悉电脑的朋友。

方法来源：尘漠中尘。

关于 2.14.0.0

2.14.0.0 是官方 2.99（关闭 MC 下载）之前的最后一个正式版，比 2.13.1.1 多了很多修复，比如：

  • 可以在版本设置里修改、添加、更新已装版本的组件；
  • 启动时可以按 Esc 取消。

已实测：正版登录、版本列表加载正常，没有下载限制。

压缩包内容

Plain Craft Launcher 2.exe   ← 官方原版，未修改
PCL/Setup.ini                ← 只有一行 SystemSystemUpdate:3（关闭自动更新）

除上述两个文件外没有别的东西。exe 是官方原版，未做任何修改；Setup.ini 的唯一作用是关掉自动更新，避免启动器把自己升级成没有下载功能的版本。

用法

1
解压到一个普通文件夹 不要直接在压缩包里双击，也不要放在临时文件夹里。建议放在 D 盘之类路径简单、不会被清理的位置，路径里尽量别有特殊符号。
2
双击 Plain Craft Launcher 2.exe 首次启动会生成配置文件，属正常现象。之后即可正版登录或离线登录，进入「下载」页面安装原版 Minecraft。
3
弹出「悲报」公告时不要点「更新 PCL」 直接关闭公告即可。点了更新就会升到 2.99，原版 Minecraft 下载功能随之消失，需要重新下载旧版 exe。
4
已经在用 PCL 的人：只替换 exe 只把 exe 替换到原来的文件夹里，不要用压缩包里的 PCL 文件夹覆盖自己的，否则设置会被冲掉。然后检查自己的 PCL/Setup.ini 里有没有 SystemSystemUpdate:3，没有就手动补上这一行。
! 替换 exe 前建议先把原来的 exe 备份一份（重命名为 Plain Craft Launcher 2.exe.bak），万一有问题可以直接换回来。

校验 SHA256

exe SHA256（官方原版，可自行核对）：

5582952DED3B443503F66C23B810802BD20F1A3E847B54D9E09653A825859A36

Windows 上核对方法：在该 exe 所在文件夹按住 Shift + 右键，选择「在此处打开 PowerShell 窗口」，执行：

certutil -hashfile "Plain Craft Launcher 2.exe" SHA256

输出的字符串与上面一致，说明文件未被篡改。macOS / Linux 可用：

shasum -a 256 "Plain Craft Launcher 2.exe"
